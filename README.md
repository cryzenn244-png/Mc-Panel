## ◈ OVERVIEW

**MC Panel** is an all-in-one server management platform built to bring VPS administration, Minecraft hosting, Discord bot management, and hosting infrastructure into one unified dashboard.

Inspired by the capabilities of established hosting panels such as Pterodactyl, MC Panel aims to combine powerful server controls with a completely refreshed interface, streamlined workflows, and a modern infrastructure management experience.

No unnecessary complexity. No outdated design. Just one unified control center for your hosting ecosystem.

> **MC PANEL — MANAGE EVERYTHING. FROM ONE PLACE.**

## 🔐 SECURITY FIRST

MC Panel is intended to manage sensitive infrastructure. Security is a core architectural requirement, not an optional feature.

- Never expose privileged agent APIs directly to the public internet without appropriate authentication and network restrictions.
- Never execute user-supplied commands through an unrestricted privileged shell.
- Isolate workloads and validate resource limits.
- Apply strict file-path validation and prevent directory traversal.
- Store credentials securely and redact secrets from logs.
- Use HTTPS for production panel access.
- Enforce authorization on every protected API operation.
- Use short-lived, revocable credentials where practical.
- Rate-limit authentication and sensitive endpoints.
- Maintain auditable logs for administrative operations.
- Validate uploads and restrict access to sensitive filesystem paths.
- Keep dependencies patched and review security advisories.
- Test backup restoration and disaster recovery.
- Never disable essential operating-system security controls for convenience.

**Responsible use:** Only deploy MC Panel on systems you own or are authorized to administer.

## ❓ FAQ

**Is MC Panel an alternative to Pterodactyl?**

MC Panel is being designed as an alternative approach to server management, with a broader scope covering Minecraft hosting, Discord bots, VPS integrations, and a modern unified interface.

**Does it support every Pterodactyl feature?**

Full feature parity is a development goal, not a verified claim. Check the implementation status and documentation for the capabilities available in each release.

**Can it manage real VPS instances?**

Yes, if the relevant virtualization platform or cloud-provider integration is implemented and configured. A web dashboard alone cannot provision independent VPS instances.

**Can I run Minecraft servers and Discord bots on the same panel?**

That is a core project goal. Each workload must have appropriate isolation, resource limits, and deployment support.
